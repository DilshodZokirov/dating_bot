Bu kurs aynan shu loyiha uchun yozilgan. Har bir darsda qisqa nazariya, o'zgartirib ko'rish mumkin bo'lgan jonli kod va mashqlar bor. Oxirgi ikki darsda esa Soyla Mini App'ining haqiqiy kodini o'qishni boshlaymiz.

Qanday o'qish kerak? Kuniga 1 dars — lekin har bir jonli kod maydonini albatta o'zgartirib ko'ring: rangni, matnni, sonni almashtiring va natija qanday o'zgarishini kuzatib boring. Faqat o'qib chiqish — o'rganish emas. Kod yozish — o'rganish.

Kursdan keyin nima qilasiz

  • Sahifa tuzilmasini o'zingiz yozasiz va DevTools bilan tekshirasiz.
  • Flexbox/Grid bilan mobil ekranga mos joylashuv qurasiz.
  • JavaScript bilan tugma, forma, ro'yxat va filtrni ishlatasiz.
  • fetch orqali o'z API'ingizdan ma'lumot olib, sahifaga chiqarasiz.
  • app/webapp/index.html faylidagi kodni tushunib, o'zgartira olasiz.

Kursni ochish

Eng oson yo'l — loyiha papkasida kichik server ishga tushirish:

python -m http.server 5500
# keyin brauzerda: http://localhost:5500/learn/

Fayllarni to'g'ridan-to'g'ri ikki marta bosib ham ochish mumkin, lekin server bilan hamma narsa (xotira, fetch) haqiqiy sayt kabi ishlaydi.
