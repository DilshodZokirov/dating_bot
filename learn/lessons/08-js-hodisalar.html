08. Hodisalar va ma'lumot saqlash

Hodisa (event) — foydalanuvchi qilgan harakat: bosdi, yozdi, formani yubordi. JavaScript shu harakatlarga javob berishi kerak. Shu darsda hodisalarni to'g'ri ushlashni va ma'lumotni brauzer xotirasida saqlashni o'rganamiz.

addEventListener — to'g'ri usul

Eng ko'p ishlatiladigan hodisalar

Hodisa obyekti (event)

Forma bilan ishlash

event.preventDefault() Forma sukut bo'yicha sahifani qayta yuklaydi. Zamonaviy ilovada (Soyla ham shunday) biz ma'lumotni JavaScript bilan yuboramiz, shuning uchun bu sukut xatti-harakatni to'xtatamiz. Havolalar uchun ham shunday ishlatiladi.

Hodisa delegatsiyasi

100 ta kartaga 100 ta ishlovchi qo'shish kerak emas. Otasiga bitta ishlovchi qo'yib, event.target orqali qaysi bolasi bosilganini aniqlaysiz. Bu, ayniqsa, kartalar keyinroq (serverdan) qo'shilganda muhim.

closest() — delegatsiyaning kaliti Foydalanuvchi tugma ichidagi matnni bosishi ham mumkin. event.target.closest("button") bosilgan joydan yuqoriga qarab eng yaqin tugmani topib beradi.

localStorage — brauzerda saqlash

Sahifa yopilib qayta ochilsa ham saqlanib qoladigan kichik xotira. Faqat matn saqlaydi — shuning uchun obyektni JSON.stringify bilan matnga aylantirib yozamiz, o'qiganda JSON.parse bilan qaytaramiz.

Sinab ko'rish Ismni yozib "Saqlash" ni bosing, keyin yuqoridagi "Ishga tushirish" tugmasini bosing — maydon o'zi to'ldiriladi. Bu kursning o'zlashtirilgan darslar belgisi ham aynan shu usulda saqlanadi.
MetodVazifasi
localStorage.setItem(kalit, matn)Yozish
localStorage.getItem(kalit)O'qish (yo'q bo'lsa null)
localStorage.removeItem(kalit)Bitta kalitni o'chirish
localStorage.clear()Hammasini o'chirish
Nimani saqlamaslik kerak localStorage — ochiq xotira, uni har qanday skript o'qiy oladi. Parol, token, to'lov ma'lumotlarini bu yerga yozmang.
Mashq — vazifalar ro'yxati (todo). Quyidagi kodni to'ldiring:
  • forma yuborilganda yangi vazifa ro'yxatga qo'shilsin (sahifa yangilanmasin);
  • bo'sh matn qo'shilmasin;
  • vazifa ustiga bosilganda "bajarildi" ko'rinishi (chizilgan matn) o'zgarsin;
  • "O'chirish" tugmasi vazifani olib tashlasin (delegatsiya bilan);
  • ro'yxat localStorage da saqlansin.
Namuna yechim 
const KALIT = "todo-royxat";

function saqla() {
  try { localStorage.setItem(KALIT, JSON.stringify(vazifalar)); } catch (err) {}
}

function yukla() {
  try {
    vazifalar = JSON.parse(localStorage.getItem(KALIT)) || [];
  } catch (err) {
    vazifalar = [];
  }
}

forma.addEventListener("submit", function (event) {
  event.preventDefault();
  const matn = kirit.value.trim();
  if (!matn) return;
  vazifalar.push({ matn: matn, bajarildi: false });
  kirit.value = "";
  chiz();
});

royxat.addEventListener("click", function (event) {
  const li = event.target.closest("li");
  if (!li) return;
  const i = Number(li.dataset.i);

  if (event.target.dataset.amal === "ochir") {
    vazifalar.splice(i, 1);
  } else {
    vazifalar[i].bajarildi = !vazifalar[i].bajarildi;
  }
  chiz();
});

Xulosa

  • addEventListener("click", ...) — hodisani ushlashning asosiy usuli.
  • Formada submit + event.preventDefault().
  • new FormData(forma) + Object.fromEntries — barcha maydonlarni bir yo'la olish.
  • Ko'p elementga bitta ishlovchi: otaga addEventListener + closest().
  • localStorage faqat matn saqlaydi → JSON.stringify / JSON.parse.
Tekshiruv savollari

1. Forma yuborilgach sahifa "sakrab" yangilandi. Nima unutilgan?
event.preventDefault().

2. Serverdan kelgan 50 ta kartaga tugma ishlovchisini qanday qo'shasiz?
Ro'yxat otasiga bitta ishlovchi qo'yib, event.target.closest("button") bilan aniqlayman.

3. localStorage ga obyektni to'g'ridan-to'g'ri yozsa nima bo'ladi?
"[object Object]" matni saqlanadi. JSON.stringify kerak.
