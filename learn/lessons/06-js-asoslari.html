06. JavaScript asoslari

Bu darsda sahifaga tegmaymiz — faqat tilni o'rganamiz: o'zgaruvchi, shart, tsikl, funksiya, massiv va obyekt. Natijani console.log() orqali ko'ramiz (o'ng tomonda qora maydon).

Birinchi kod

console.log — o'rganishning asosiy quroli Kod nima qilayotganini bilmasangiz, oraga console.log(...) qo'yib qiymatni chiqaring. Haqiqiy brauzerda u F12 → Console bo'limida ko'rinadi.

O'zgaruvchilar: let va const

  • Sukut bo'yicha const yozing. Faqat qiymat o'zgarishi kerak bo'lsa — let.
  • var — eski usul, yangi kodda ishlatilmaydi.

Ma'lumot turlari

Template string — matnni yopishtirishning qulay yo'li

Shartlar

Har doim === ishlating == turlarni o'zi o'zgartirib solishtiradi va kutilmagan natija beradi (0 == "" → true). Professional kodda faqat === va !==.

"Rost" va "yolg'on" qiymatlar

Tsikllar

Funksiyalar

return ni unutmang Funksiya return yozmasa, undefined qaytaradi. Bu yangi boshlovchilarning eng ko'p uchraydigan xatosi.

Massivlar

Massivning eng muhim 4 metodi

Shu 4 metod — kundalik ishning 80%i map — o'zgartirish, filter — saralash, find — topish, sort — tartiblash. Yakuniy loyihada (10-dars) aynan shular bilan qidiruv filtri yozamiz.

Obyektlar

Mashq — mos suhbatdoshni topish. Quyidagi kodda mosKeladi funksiyasini yozib tugatib, filtr ishlashiga erishing. Shartlar:
  • yoshi quyi va yuqori orasida bo'lsin (chegaralar ham hisoblanadi);
  • tili qidiruvchi tili bilan bir xil bo'lsin;
  • online bo'lsin.
Namuna yechim 
function mosKeladi(odam, qidiruv) {
  if (!odam.online) return false;
  if (odam.til !== qidiruv.til) return false;
  if (odam.yosh < qidiruv.quyi) return false;
  if (odam.yosh > qidiruv.yuqori) return false;
  return true;
}

// yoki bir qatorda:
const mosKeladi = (odam, q) =>
  odam.online && odam.til === q.til && odam.yosh >= q.quyi && odam.yosh <= q.yuqori;

Birinchi variant o'qishga qulayroq: har bir shart alohida qatorda, xato qidirish oson.

Xulosa

  • const asosiy, let — faqat o'zgaradigan qiymatga.
  • Matn yasashda backtick va ${...}.
  • Solishtirishda faqat ===.
  • map / filter / find / sort — massiv bilan ishlashning asosi.
  • Obyekt — nom va qiymat juftliklari; obyekt.maydon bilan o'qiladi.
Tekshiruv savollari

1. "5" + 2 nima beradi?
"52" — chunki + matn bilan ishlaganda yopishtiradi.

2. map va forEach farqi?
map yangi massiv qaytaradi, forEach hech nima qaytarmaydi — faqat harakat qiladi.

3. Massivning 10 elementidan shartga mos 3 tasini olish uchun nima ishlatasiz?
filter.
