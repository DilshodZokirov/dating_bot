07. DOM: sahifani o'zgartirish

DOM — brauzer sizning HTML'ingizdan yasagan "daraxt". JavaScript shu daraxtni o'zgartira oladi: matnni almashtirish, rang berish, yangi element qo'shish, o'chirish. Shu yerdan sahifa "jonlanadi".

Skript qayerda turadi

<body>
  <h1 id="sarlavha">Salom</h1>

  <script>
    // Skript body oxirida bo'lishi kerak:
    // shunda HTML allaqachon yuklangan bo'ladi.
    document.getElementById("sarlavha").textContent = "Yangi matn";
  </script>
</body>
Eng ko'p uchraydigan xato: null Cannot set property of null xatosi — demak skript elementdan oldin ishlagan yoki selektor xato yozilgan. Yechim: skriptni body oxiriga qo'yish (yoki <script defer> ishlatish).

Element topish

UsulNimani qaytaradi
getElementById("x")Bitta element yoki null
querySelector(".x")Birinchi mos element yoki null
querySelectorAll(".x")Barcha mos elementlar ro'yxati (bo'sh bo'lishi mumkin)

Matn va HTML'ni o'zgartirish

Xavfsizlik qoidasi Foydalanuvchi kiritgan matnni (ism, izoh, xabar) hech qachon innerHTML ga qo'ymang — ular ichida zararli skript bo'lishi mumkin (XSS hujumi). Foydalanuvchi matni uchun har doim textContent.

Class qo'shish va olib tashlash

Uslubni JS'dan bermang — class bering element.style.background = "green" emas, balki element.classList.add("faol"). Shunda dizayn CSS'da, mantiq JS'da qoladi — kod ancha toza bo'ladi.

Ro'yxatni ma'lumotdan yasash — eng muhim namuna

Real ilovada ma'lumot massivda keladi (serverdan), siz esa undan HTML yasaysiz. Soyla'dagi "Saqlangan suhbatdoshlar" ro'yxati ham shunday ishlaydi:

Mashq — hisoblagich. Quyidagi kodni to'ldiring:
  • "+" tugmasi sonni oshirsin, "−" kamaytirsin, "Tozalash" nolga qaytarsin;
  • son 0 dan katta bo'lsa matn yashil, 0 bo'lsa kulrang bo'lsin (class orqali!);
  • son 10 ga yetganda "+" tugmasi disabled bo'lsin.
Namuna yechim 
function chiz() {
  sonEl.textContent = qiymat;
  sonEl.classList.toggle("bor", qiymat > 0);
  plusEl.disabled = qiymat >= 10;
}

plusEl.onclick = () => { qiymat++; chiz(); };
document.getElementById("minus").onclick = () => { qiymat--; chiz(); };
document.getElementById("tozala").onclick = () => { qiymat = 0; chiz(); };

chiz();

classList.toggle("bor", shart) — ikkinchi parametr true bo'lsa qo'shadi, false bo'lsa olib tashlaydi. Juda qulay.

Xulosa

  • document.querySelector — element topishning asosiy usuli.
  • Matn uchun textContent (xavfsiz), HTML uchun innerHTML (ehtiyot bilan).
  • Ko'rinishni classList bilan boshqaring, style bilan emas.
  • createElement + append — yangi element qo'shish.
  • Ma'lumot massividan HTML yasash — frontend ishining asosi.
Tekshiruv savollari

1. querySelector("karta") nega ishlamaydi?
Class uchun nuqta kerak: querySelector(".karta").

2. Foydalanuvchi yozgan ismni sahifaga qanday chiqarasiz?
textContent bilan — innerHTML XSS xavfini tug'diradi.

3. data-user-id ni JS'da qanday o'qiysiz?
element.dataset.userId.
