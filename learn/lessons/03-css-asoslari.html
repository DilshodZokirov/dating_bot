03. CSS asoslari

CSS — sahifaning ko'rinishi. Bitta qoida ikki qismdan iborat: kimga (selektor) va nima qilish (xossalar).

CSS qoidasi tuzilishi

h1 {                    ← selektor: barcha h1 teglar
  color: #e86f4a;       ← xossa: qiymat;
  font-size: 32px;
}                       ← qoida tugadi

CSS'ni HTML'ga ulashning 3 yo'li

Qaysi biri kuchli? Inline uslub eng kuchli, keyin style tegi / fayl, keyin brauzerning o'z uslubi. Shuning uchun inline uslubni keyin CSS bilan bekor qilish qiyin — undan kamroq foydalaning.

Selektorlar

Amaliy maslahat Kundalik ishda 90% holatda class ishlatiladi. id asosan JavaScript uchun va sahifa ichidagi havolalar uchun qoldiriladi.

Rang, shrift, matn

Box model — CSS'ning yuragi

Har bir element to'rtburchak "quti". Uning o'lchami 4 qatlamdan yig'iladi:

┌─────────── margin (tashqi bo'shliq) ───────────┐
│  ┌───────── border (chegara) ─────────────┐    │
│  │  ┌────── padding (ichki bo'shliq) ──┐  │    │
│  │  │        content (kontent)         │  │    │
│  │  └──────────────────────────────────┘  │    │
│  └────────────────────────────────────────┘    │
└────────────────────────────────────────────────┘
box-sizing: border-box nima qiladi? Sukut bo'yicha width: 200px faqat kontent uchun bo'ladi, padding va border ustiga qo'shiladi → element 248px chiqadi. border-box bilan esa 200px — hammasi bilan 200px. Shu sababli deyarli har bir loyiha * { box-sizing: border-box; } dan boshlanadi (Soyla'da ham shunday).

CSS o'zgaruvchilari

Bir xil rangni 20 joyda takrorlash — muammo: birini o'zgartirsangiz, qolganini unutasiz. Yechim — o'zgaruvchi. Soyla kodining boshida aynan shunday qilingan:

Mashq — profil kartasi. Quyidagi HTML berilgan. Faqat CSS yozib, uni chiroyli kartaga aylantiring:
  • oq fon, yumaloq burchak (16px), yengil soya (box-shadow);
  • ichki bo'shliq 20px, kenglik 300px;
  • ism — qalin va katta, shahar — kulrang va kichik;
  • tugma — to'q sariq fon, oq matn, chegarasiz, yumaloq;
  • tugma ustiga sichqoncha kelganda rangi to'qlashsin.

Xulosa

  • Qoida = selektor + { xossa: qiymat; }
  • Class — nuqta (.karta), id — panjara (#asosiy).
  • Box model: content → padding → border → margin.
  • box-sizing: border-box ni har doim yozing.
  • Takrorlanadigan qiymatlarni :root da o'zgaruvchiga oling.
Tekshiruv savollari

1. .karta.faol va .karta .faol farqi?
Birinchisi — ikkala class ham bitta elementda. Ikkinchisi — .karta ichidagi .faol element.

2. padding va margin farqi?
padding — chegara ichidagi bo'shliq (fon rangi bor). margin — chegaradan tashqaridagi bo'shliq.

3. Ranglarni bir joydan boshqarish uchun nima qilasiz?
:root ichida --accent kabi o'zgaruvchi e'lon qilib, var(--accent) bilan ishlataman.
