11. Soyla kodini o'qishni boshlash

Endi bilimingizni o'z loyihangizga qo'llaymiz. app/webapp/index.html — 4000 qatordan ortiq fayl. Uni boshdan-oxir o'qish kerak emas: kerakli joyni topib, faqat shu qismni tushunish kerak. Shu darsda buni qanday qilishni ko'rsatamiz.

Fayl xaritasi

Fayl uch katta qismdan iborat:

QismTaxminan qayerdaNima bor
headBoshidan ~11-qatorgachaShrift, telegram-web-app.js, LiveKit kutubxonasi
<style>~12–1066Butun dizayn: :root o'zgaruvchilari, oynalar, kartalar, pastki menyu
<body> markup~1068–1390To'rt oyna (searchView, profileView, savedView, adminView) va pastki menyu
<script>~1391–4181Tarjimalar, API chaqiruvlar, qidiruv, qo'ng'iroq, admin panel
Qator raqamlari o'zgaradi Kod yangilanganda raqamlar suriladi. Shuning uchun qator raqamiga emas, qidirishga tayanish kerak: VS Code'da Ctrl+F (fayl ichida) yoki Ctrl+Shift+F (butun loyiha bo'ylab).

Naqsh 1 — oynalarni almashtirish

Mini App'da sahifa yangilanmaydi. Barcha "sahifalar" bir faylda turadi va CSS orqali biri ko'rsatiladi, qolgani yashiriladi. Siz bu naqshni 07 va 10-darslarda ko'rdingiz: 

/* CSS: faqat active bo'lgani ko'rinadi */
.view { display: none; }
.view.active { display: flex; }
// JS: pastki menyu tugmasi bosilganda class'lar almashtiriladi
document.querySelectorAll(".nav-btn").forEach((btn) => {
  btn.addEventListener("click", () => {
    document.querySelectorAll(".nav-btn").forEach((b) => b.classList.remove("active"));
    document.querySelectorAll(".view").forEach((v) => v.classList.remove("active"));
    btn.classList.add("active");
    document.getElementById(btn.dataset.view).classList.add("active");
    if (btn.dataset.view === "savedView") loadSavedList();
    if (btn.dataset.view === "adminView") loadAdminPanel();
  });
});

Tanish narsalar: querySelectorAll (07-dars), addEventListener (08-dars), classList (07-dars), dataset (07-dars). Yangi hech nima yo'q.

Naqsh 2 — api() yordamchisi

Har bir so'rovda sarlavhalarni qayta yozmaslik uchun bitta yordamchi funksiya yozilgan. Bu 09-darsdagi fetch ning aynan o'zi, faqat qulay o'ramda: 

async function api(path, options = {}) {
  refreshTelegramContext();
  const res = await fetch(path, {
    ...options,
    headers: {
      "Content-Type": "application/json",
      "X-Telegram-Init-Data": initData,       // server foydalanuvchini tekshiradi
      "ngrok-skip-browser-warning": "true",
      ...(options.headers || {}),
    },
  });
  if (!res.ok) {
    const body = await res.json().catch(() => ({}));
    throw new Error(body.detail || `Error: ${res.status}`);
  }
  return res.json();
}
  • ...options — "spread": berilgan sozlamalarni nusxalab qo'yadi.
  • X-Telegram-Init-Data — Telegram bergan imzo. Server app/telegram_auth.py da uni tekshirib, so'rov haqiqatan shu foydalanuvchidan kelganiga ishonch hosil qiladi.
  • if (!res.ok) throw — 09-darsdagi qoida: fetch o'zi xato bermaydi.
  • Natijada har joyda shunchaki await api("/api/me") deb yozish kifoya.

Naqsh 3 — holatni davriy tekshirish (polling)

Suhbatdosh topilganini bilish uchun ilova serverga har necha soniyada "nima bo'ldi?" deb so'raydi: 

poolTimer = setInterval(refreshPoolCount, 8000);   // har 8 soniyada
// to'xtatish uchun:
clearInterval(poolTimer);

setInterval — setTimeout ning takrorlanuvchi shakli (09-dars). Muhim qoida: yangi taymer boshlashdan oldin eskisini clearInterval bilan to'xtatish, aks holda ular ustma-ust to'planib, so'rovlar soni ko'payib ketadi.

Naqsh 4 — tarjimalar

Har bir matn to'g'ridan-to'g'ri yozilmagan, balki lug'atdan olinadi:

const TRANSLATIONS = {
  idle_title: { uz: "Yangi suhbatni boshlang", ru: "Начните новый разговор", en: "Start a new chat" },
  // ...
};

function tr(key, vars) { /* tanlangan tildagi matnni qaytaradi */ }

Shuning uchun yozuvni o'zgartirmoqchi bo'lsangiz, HTML'dan emas — TRANSLATIONS dan qidirish kerak. Bu obyekt ichida obyekt (06-dars).

Kerakli joyni topish usuli

  1. Ekranda ko'rgan matnni qidiring. Masalan "Saqlangan" so'zini — TRANSLATIONS yoki markup'dan topasiz.
  2. Tugmadan boshlab yuring. Tugmaning id sini toping, keyin shu id ni qidiring — addEventListener ni topasiz. Undan keyin chaqirilgan funksiyaga o'tasiz.
  3. So'rovdan boshlab yuring. Brauzerda F12 → Network'da qaysi manzilga so'rov ketganini ko'rib, shu manzilni kodda qidiring (masalan /api/saved).
  4. Xatodan boshlab yuring. Console'dagi xato yozuvida qator raqami bo'ladi — bosing, to'g'ri joyga olib boradi.
Mashq 1 — kodni kuzatish (o'zgartirishsiz). app/webapp/index.html ni VS Code'da ochib, quyidagilarni toping va daftaringizga qator raqamini yozib qo'ying:
  1. :root ichidagi --accent rangi qanday qiymatda?
  2. .view.active qoidasi qayerda?
  3. Pastki menyudagi to'rtta tugma data-view qiymatlari qanday?
  4. api() funksiyasi qayerda e'lon qilingan va u nechta joyda chaqirilgan?
  5. loadSavedList() funksiyasi qaysi qatordan boshlanadi? U api() ni chaqiradimi?
Mashq 2 — birinchi xavfsiz o'zgartirish. Eng oson va foydali o'zgartirish — rang:
  1. app/webapp/index.html boshidagi :root blokini toping.
  2. --accent qiymatini boshqa rangga o'zgartiring (masalan #7c5cff).
  3. Saqlang, Mini App'ni qayta yuklang.
  4. Butun ilova rangi o'zgarganini ko'rasiz — chunki hamma joyda var(--accent) ishlatilgan (03-dars).
  5. Yoqmasa, eski qiymatni qaytaring yoki git checkout -- app/webapp/index.html bilan bekor qiling.
O'zgartirishni qanday sinash mumkin index.html — statik fayl, u volume orqali ulangan. Ya'ni faylni saqlab, Telegram'da Mini App'ni yopib-ochsangiz (yoki brauzerda Ctrl+Shift+R) yangi kod ko'rinadi — docker compose ni qayta qurish kerak emas. Faqat Python kodini o'zgartirganda konteynerni qayta ishga tushirish kerak bo'ladi.

Kod hajmidan qo'rqmaslik

4000 qator — ko'p ko'rinadi, lekin u bir xil naqshlarning takroridan iborat:

  • element top (getElementById) → addEventListener qo'sh → funksiya chaqir;
  • funksiya api() bilan serverga boradi → javobni oladi;
  • javobdan createElement bilan kartalar yasaydi;
  • classList bilan holatni ko'rsatadi (yuklanmoqda / xato / tayyor).

Shu to'rtta naqshni bilsangiz, faylning istalgan joyini tushunishga qurol yetarli. Qolgani — mashq.

Keyin nima o'rganish kerak

  1. Git — branch, commit, diff. Kod o'zgartirishdan qo'rqmaslik uchun eng foydali ko'nikma.
  2. DevTools chuqurroq — Network'da so'rovlarni o'qish, Elements'da CSS'ni jonli tahrirlash.
  3. Kengaytirilgan JS — modullar (import/export), class, try/catch naqshlari.
  4. Kodni bo'lish — bitta katta index.html ni style.css va app.js ga ajratish.
  5. Keyin — xohlasangiz React yoki Vue. Lekin faqat shu darslar mustahkam bo'lganda: ular ham oxirida HTML, CSS va JS yasaydi.
Mustaqil mashq uchun eng yaxshi usul Har hafta Soyla'ga bitta kichik ko'rinish o'zgartirishi kiritib ko'ring: tugma shakli, bo'shliqlar, yangi belgi (badge), bo'sh ro'yxat uchun chiroyli xabar. Kichik o'zgarishlar — eng tez o'rganish yo'li.

Xulosa

  • Katta faylni qidirish orqali o'qing, boshdan-oxir emas.
  • Soyla'dagi asosiy naqshlar: oyna almashtirish, api() yordamchisi, polling, tarjimalar.
  • Birinchi o'zgartirishni :root ranglaridan boshlang — xavfsiz va natijasi darhol ko'rinadi.
  • Git bilan har qanday o'zgarishni bekor qilish mumkin — shuning uchun tajriba qilishdan qo'rqmang.
