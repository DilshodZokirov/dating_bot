00. Web qanday ishlaydi

Kod yozishdan oldin 10 daqiqa nazariya. Keyin birinchi sahifani o'zingiz yozasiz — shu yerda, brauzerdan chiqmasdan.

Uchta til, uchta vazifa

Har qanday sayt — hatto Instagram ham — asosini shu uchta til tashkil qiladi:

TilVazifasiUy misolida
HTMLSahifada nima bor: matn, rasm, tugma, formaG'isht va devorlar
CSSU qanday ko'rinadi: rang, o'lcham, joylashuvBo'yoq, mebel, dizayn
JavaScriptU nima qiladi: bosilganda javob beradi, ma'lumot oladiChiroq, lift, eshik qulfi

Ularni shu tartibda o'rganamiz, chunki CSS HTML ustiga, JavaScript ikkalasi ustiga qo'yiladi. Tartibni buzib bo'lmaydi: devorsiz uyni bo'yash mumkin emas.

Brauzer, server va sizning loyihangiz

Siz brauzerda sahifani ochganingizda quyidagi zanjir ishlaydi:

  1. Brauzer serverga so'rov yuboradi: "menga shu sahifani ber".
  2. Server HTML faylni qaytaradi.
  3. Brauzer HTML'ni o'qib, unda ko'rsatilgan CSS va JS fayllarni ham so'raydi.
  4. Hammasini birlashtirib ekranga chizadi (render qiladi).
  5. Keyin JavaScript ishlaydi va sahifani jonlantiradi.
Soyla loyihasida bu qanday? app/api/webapp.py — server (Python, FastAPI). U app/webapp/index.html faylni brauzerga beradi. Telegram esa shu sahifani ilova ichida ko'rsatadi. Ya'ni siz o'rganayotgan HTML/CSS/JS — aynan app/webapp/index.html ichidagi kod.

Frontend va backend

  • Frontend — foydalanuvchi ko'rayotgan qism, brauzerda ishlaydi (HTML, CSS, JS).
  • Backend — server tomoni, foydalanuvchi ko'rmaydi (bu loyihada Python + PostgreSQL + Redis).

Bu kurs — frontend haqida. Lekin 09-darsda ikkisi qanday gaplashishini ham ko'ramiz.

Birinchi sahifangiz

Quyida jonli kod maydoni. Chap tomonda kod, o'ng tomonda natija. Kodni o'zgartirsangiz, natija o'zi yangilanadi (yoki "Ishga tushirish" ni bosing). "Boshidan" tugmasi boshlang'ich holatga qaytaradi — buzib qo'yishdan qo'rqmang.

Mashq 1. Yuqoridagi kodda:
  1. Salom, dunyo! o'rniga o'z ismingizni yozing.
  2. Paragraf matnini o'zgartiring.
  3. <p>...</p> qatorini nusxalab, yana bitta paragraf qo'shing.

Shu 6 qator nima degani?

KodMa'nosi
<!DOCTYPE html>"Bu zamonaviy HTML fayl" — har doim birinchi qatorda turadi.
<html lang="uz">Butun sahifaning tashqi qobig'i. lang — sahifa tili.
<head>Ko'rinmaydigan sozlamalar: sarlavha, kodlash, CSS havolalari.
<meta charset="UTF-8">O'zbek harflari (o', g', ʼ) to'g'ri ko'rinishi uchun. Bo'lmasa — "krakozyabra".
<title>Brauzer yorlig'idagi (tab) yozuv.
<body>Ekranda ko'rinadigan hamma narsa shu yerda.

O'z kompyuteringizda ishlash

Kurs brauzerda ishlaydi, lekin real ish quyidagicha bo'ladi:

  1. VS Code o'rnatasiz (bepul muharrir).
  2. Papka yaratasiz, ichida index.html fayl.
  3. Faylni yozib, brauzerda ochasiz (yoki VS Code'ning Live Server kengaytmasi bilan).
  4. Kodni o'zgartirasiz → saqlaysiz (Ctrl+S) → brauzerni yangilaysiz (F5).
DevTools — eng muhim asbob Brauzerda F12 (yoki Ctrl+Shift+I) bosing.
  • Elements — sahifaning HTML va CSS'ini ko'rish/vaqtincha o'zgartirish.
  • Console — JavaScript xatolari shu yerda chiqadi. Sayt "ishlamasa", birinchi shu yerga qarang.
  • Network — qanday so'rovlar ketdi va server nima javob berdi.
Yangi boshlovchilar 90% muammosini DevTools'ni ochishni o'rganish bilan hal qiladi.

Fayl tuzilishi qanday bo'ladi

mening-saytim/
├── index.html      ← asosiy sahifa
├── style.css       ← uslublar
├── app.js          ← skript
└── images/
    └── logo.png

Soyla'da esa hammasi bitta faylda: HTML, CSS (<style> ichida) va JS (<script> ichida). Kichik loyiha uchun bu normal yo'l.

Xulosa

  • HTML — tuzilma, CSS — ko'rinish, JS — harakat.
  • Brauzer HTML'ni o'qib, CSS va JS'ni yuklab, sahifani chizadi.
  • Har bir HTML fayl <!DOCTYPE html> bilan boshlanadi, head va body dan iborat.
  • F12 — sizning eng yaxshi do'stingiz.
Tekshiruv savollari (javobni ko'rish uchun bosing)

1. head va body farqi nima?
head — ko'rinmaydigan sozlamalar (sarlavha, kodlash, CSS havolasi). body — ekranda ko'rinadigan kontent.

2. O'zbek harflari kvadratchaga aylanib qolsa, nimani tekshirasiz?
<meta charset="UTF-8"> borligini.

3. Tugma bosilganda oyna chiqishi kerak — bu qaysi tilning ishi?
JavaScript.
