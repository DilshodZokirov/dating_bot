10. Yakuniy loyiha: suhbatdoshlar ro'yxati

Endi hammasini birlashtiramiz. Beshta qadamda to'liq ishlaydigan sahifa yasaymiz: serverdan ma'lumot oladi, kartalar chizadi, qidiruv va filtrlarni qo'llaydi, saqlanganlarni brauzer xotirasida eslab qoladi.

Qanday ishlash kerak Har bir qadamni o'qib, kodni o'zingiz o'zgartirib ko'ring: rangni, matnni, shartni. Oxirgi qadamda to'liq ilova bo'ladi — uni o'z kompyuteringizda index.html fayliga ko'chirib, mustaqil loyiha sifatida saqlab qo'yishingiz mumkin.

Qadam 1 — HTML skeleti

Avval faqat tuzilma: sarlavha, qidiruv maydoni, filtrlar va ro'yxat uchun bo'sh joy. Hech qanday bezak yo'q — shunday bo'lishi kerak. Avval tuzilma, keyin ko'rinish.

Qadam 2 — CSS bilan ko'rinish

Xuddi shu HTML, lekin endi bezatilgan: CSS o'zgaruvchilari, Flexbox, Grid, soya va moslashuvchan to'r. Hech qanday JavaScript hali yo'q.

Qadam 3 — ma'lumotdan kartalar chizish

Kartalarni qo'lda yozish mumkin emas — ular serverdan keladi. Shuning uchun ma'lumot massivi va uni HTML'ga aylantiruvchi chiz() funksiyasi kerak. Bu — frontend ishining yuragi.

Asosiy g'oya: ma'lumot → ko'rinish HTML'ni qo'lda o'zgartirmaysiz. Ma'lumotni o'zgartirasiz va chiz() ni qayta chaqirasiz. React, Vue kabi kutubxonalar ham xuddi shu g'oyani avtomatlashtiradi.

Qadam 4 — qidiruv va filtrlar

Endi filter ni ishga solamiz. Har qanday filtr o'zgarganda: ma'lumotni saralaymiz → qaytadan chizamiz.

Mashq. Yuqoridagi kodga quyidagilarni qo'shib ko'ring:
  • eng kichik yosh uchun ham filtr;
  • shahar bo'yicha select (variantlarni odamlar dan [...new Set(odamlar.map(o => o.shahar))] bilan yasash mumkin);
  • natijani yosh bo'yicha tartiblash (sort).

Qadam 5 — to'liq ilova: fetch + saqlanganlar

Yakuniy versiya: ma'lumot serverdan (fetch) keladi, yuklanish va xato holatlari ko'rsatiladi, saqlangan suhbatdoshlar localStorage da qoladi, tab almashtirish ham bor. Bu — kichik, lekin haqiqiy ilova.

Loyihani rivojlantirish (mustaqil ish). Bittasini tanlab bajarib ko'ring:
  • Tartiblash: "Yoshi bo'yicha / Ismi bo'yicha" select qo'shib, sort qo'llang.
  • Shahar filtri: shaharlar ro'yxatini ma'lumotdan avtomatik yasang.
  • Tungi/kunduzgi rejim: body ga light class qo'shib, CSS o'zgaruvchilarini almashtiring va tanlovni localStorage da saqlang.
  • Batafsil oyna: kartani bosganda modal oyna chiqib, odam haqida to'liq ma'lumot ko'rsatilsin.
  • Debounce: qidiruvni har harfda emas, 300ms tinchlikdan keyin ishga tushiring (setTimeout + clearTimeout).

Xulosa

  • Ishni tartib bilan qiling: HTML tuzilma → CSS ko'rinish → JS mantiq.
  • Ma'lumotni holat (state) sifatida saqlang, ko'rinishni chiz() funksiyasi yasasin.
  • Hodisa → holatni o'zgartir → qayta chiz. Bu naqsh barcha frontend ilovalarida bir xil.
  • Foydalanuvchiga har doim holatni ko'rsating: yuklanmoqda, bo'sh, xato.
