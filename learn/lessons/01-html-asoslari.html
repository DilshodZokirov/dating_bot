01. HTML asoslari

HTML — teglardan iborat. Teg brauzerga "bu matn sarlavha", "bu rasm", "bu havola" deb aytadi. Shu darsda kerak bo'ladigan barcha asosiy teglarni o'rganamiz.

Teg qanday tuzilgan

<p class="izoh">Salom</p>
 │    │            │      │
 │    │            │      └── yopilish tegi
 │    │            └───────── kontent (matn)
 │    └────────────────────── atribut (nom="qiymat")
 └─────────────────────────── ochilish tegi, teg nomi: p

Ba'zi teglar kontentga ega emas va yopilmaydi — ular bo'sh teglar:

<br>          <!-- qatorni uzish -->
<hr>          <!-- gorizontal chiziq -->
<img src="..." alt="...">
<input type="text">
Eng ko'p uchraydigan xato Tegni yopishni unutish. <div> ochib, </div> yozmasangiz, sahifa "buzilib" ketadi. VS Code teglarni avtomatik yopadi — shuning uchun muharrirdan foydalanish muhim.

Matn teglari

  • h1–h6 — sarlavhalar. Sahifada bitta h1 bo'lishi to'g'ri.
  • p — paragraf, oddiy matn uchun asosiy teg.
  • strong — muhim (qalin), em — urg'u (qiya).
  • br — qator uzish, hr — ajratuvchi chiziq.
Nega h2 ni shrift kattaligi uchun ishlatmaslik kerak? Sarlavha teglari ma'no beradi: qidiruv tizimlari va ekran o'quvchilari shu tartibga qaraydi. Shriftni kattalashtirish — CSS'ning ishi, teg tanlashning emas.

Ro'yxatlar

Havolalar

  • href — qayerga olib borishi.
  • target="_blank" — yangi yorliqda ochish (tashqi saytlar uchun).
  • href="#id" — shu sahifadagi elementga o'tish.

Rasmlar

alt ni hech qachon tashlab ketmang U: (1) rasm yuklanmasa matn ko'rsatadi, (2) ko'zi ojiz foydalanuvchiga rasmni tushuntiradi, (3) qidiruv tizimi uchun ma'lumot beradi.

Guruhlash: div va span

Bu ikki teg hech qanday ko'rinish bermaydi — ular faqat o'rash uchun. Keyinchalik CSS bilan ularni bezaymiz.

  • div — blok: butun qator egallaydi, yangi qatordan boshlanadi.
  • span — satr ichida: faqat o'z matni joyini egallaydi.

Semantik teglar

Hammasini div bilan yozish mumkin, lekin ma'noli teglar kodni tushunarli qiladi:

TegNima uchun
headerYuqori qism: logo, sarlavha
navMenyu, navigatsiya havolalari
mainSahifaning asosiy kontenti (bitta bo'ladi)
sectionMavzuli bo'lim
articleMustaqil birlik: post, karta, yangilik
asideYon qism, qo'shimcha ma'lumot
footerPastki qism
buttonBosiladigan tugma (div emas!)

Izohlar

<!-- Bu izoh. Brauzer uni ko'rsatmaydi. -->
<!-- Vaqtincha o'chirib qo'yish uchun ham ishlatiladi:
<button>Hali tayyor emas</button>
-->
Mashq 2 — o'z profil sahifangiz. Quyidagi bo'sh maydonga o'zingiz haqida sahifa yozing. Shartlar:
  • header ichida h1 — ismingiz;
  • bitta rasm (alt bilan);
  • ul — 3 ta qiziqishingiz;
  • ol — o'rganmoqchi bo'lgan 3 narsa;
  • bitta tashqi havola (target="_blank" bilan);
  • footer ichida yil.
Mashq 2 — namuna yechim 
<header>
  <h1>Dilshod</h1>
  <p>Telegram bot ishlab chiquvchi</p>
</header>

<main>
  <img src="https://picsum.photos/seed/me/200/200" alt="Mening rasmim" width="200">

  <h2>Qiziqishlarim</h2>
  <ul>
    <li>Python</li>
    <li>Telegram botlar</li>
    <li>Shaxmat</li>
  </ul>

  <h2>O'rganmoqchiman</h2>
  <ol>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
  </ol>

  <p><a href="https://telegram.org" target="_blank" rel="noopener">Telegram</a></p>
</main>

<footer><small>2026</small></footer>

Xulosa

  • Teg = ochilish + kontent + yopilish. Bo'sh teglar yopilmaydi.
  • Atributlar tegga qo'shimcha ma'lumot beradi: href, src, alt, class, id.
  • div — blok, span — satr ichida.
  • Ma'noli teglarni tanlang: tugma uchun button, bo'lim uchun section.
Tekshiruv savollari

1. <strong> va <div style="font-weight:bold"> — qaysi biri to'g'ri?
Matn muhim bo'lsa — strong. Faqat ko'rinish uchun qalin kerak bo'lsa — CSS.

2. Sahifada nechta h1 bo'lishi kerak?
Bitta.

3. id va class farqi?
id — sahifada yakka, faqat bitta elementda. class — ko'p elementda takrorlanishi mumkin.
