04. Joylashuv: Flexbox va Grid

Elementlarni yonma-yon qo'yish, markazlashtirish, ular orasida bo'shliq qoldirish — hammasi shu darsda. Bu CSS'ning eng ko'p kerak bo'ladigan qismi.

Avval: blok va satr elementlari

Flexbox — bir o'lchovli joylashuv

Flexbox elementlarni bir qatorda (yoki bir ustunda) joylashtiradi. Sirri shunda: display: flex ni ota elementga yozasiz, bolalari avtomatik moslashadi.

Flex'ning asosiy xossalari

XossaNima qiladi
flex-directionrow (sukut, gorizontal) / column (vertikal)
justify-contentAsosiy o'q bo'ylab taqsimlash: flex-start, center, flex-end, space-between, space-around
align-itemsKo'ndalang o'q bo'ylab: stretch (sukut), center, flex-start, flex-end
gapElementlar orasidagi bo'shliq
flex-wrapwrap — joy yetmasa keyingi qatorga o'tsin
flex: 1Bolaga beriladi: bo'sh joyni egallasin
Eng ko'p kerak bo'ladigan 3 qator Biror narsani markazga qo'yish kerak bo'lsa: display: flex; justify-content: center; align-items: center; — bu retsept minglab marta ishlatiladi.

flex: 1 — bo'sh joyni bo'lish

Grid — ikki o'lchovli joylashuv

Flexbox bir chiziq bo'ylab ishlaydi, Grid esa ustun va qatorlar to'ri yasaydi. Kartalar galereyasi uchun ideal.

XossaNima qiladi
grid-template-columns: 1fr 2frIkki ustun, ikkinchisi ikki barobar keng
repeat(3, 1fr)1fr 1fr 1fr ning qisqa yozuvi
repeat(auto-fit, minmax(140px, 1fr))Ekranga qarab ustun sonini o'zi tanlaydi
gap: 12pxYacheykalar orasidagi bo'shliq
grid-column: span 2Bolaga: ikki ustunni egallasin

position — erkin joylashtirish

QiymatMa'nosi
staticSukut holat, oddiy oqimda
relativeO'z joyida qoladi, lekin top/left bilan siljitiladi; bolalari uchun tayanch bo'ladi
absoluteOqimdan chiqadi, eng yaqin relative otaga nisbatan joylashadi
fixedEkranga yopishadi, skrollda joyida qoladi
stickySkroll qilinsa ma'lum joyda "yopishib" turadi (bu kursdagi yuqori panel shunday)

z-index — bir-birining ustidagi elementlar tartibi. Kattasi ustida turadi (faqat position berilgan elementlarda ishlaydi).

Mashq — suhbatdosh kartalari to'ri. Quyidagi 5 ta kartani:
  • Grid bilan moslashuvchi to'rga joylashtiring (kamida 160px, auto-fit);
  • har bir karta ichida avatar va matn yonma-yon bo'lsin (Flexbox, gap: 12px, align-items: center);
  • kartaga oq fon, yumaloq burchak va soya bering.
Namuna yechim 
.royxat {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(160px, 1fr));
  gap: 12px;
}
.karta {
  display: flex;
  align-items: center;
  gap: 12px;
  background: #fff;
  padding: 12px;
  border-radius: 14px;
  box-shadow: 0 6px 18px rgba(0, 0, 0, 0.08);
}

Xulosa

  • display: flex — bir qator/ustun; display: grid — to'r.
  • Markazlashtirish: justify-content: center; align-items: center;
  • gap — bo'shliq uchun eng qulay xossa (margin bilan kurashmang).
  • flex: 1 bolaga beriladi — bo'sh joyni egallaydi.
  • Moslashuvchi to'r retsepti: repeat(auto-fit, minmax(160px, 1fr)).
  • absolute ishlashi uchun otada relative bo'lishi kerak.
Tekshiruv savollari

1. display: flex ni otaga yozamizmi, bolaga?
Otaga. flex: 1 esa bolaga.

2. Kartalar galereyasi uchun Flex yoki Grid?
Grid — ustun va qatorlarni birga boshqaradi.

3. Avatar ustidagi "online" nuqtasini qanday qo'yamiz?
Otaga position: relative, nuqtaga position: absolute + bottom/right.
