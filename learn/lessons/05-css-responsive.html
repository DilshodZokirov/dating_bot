05. Moslashuvchan dizayn va animatsiya

Soyla — Telegram ichida, ya'ni telefonda ishlaydi. Shuning uchun mobil ekran birinchi o'rinda. Shu darsda sahifani har qanday ekranga moslashtirishni va yumshoq animatsiya qo'shishni o'rganamiz.

Birinchi qadam: viewport meta tegi

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Bu qator bo'lmasa, telefon sahifani 980px kenglikda ochib, keyin kichraytiradi — matn juda mayda bo'lib qoladi. Har bir HTML faylda bu qator bo'lishi shart.

Media query — ekran o'lchamiga qarab uslub

Mobile-first yondashuv Avval telefon uchun yozing (oddiy, bitta ustun), keyin @media (min-width: ...) bilan kengroq ekranlar uchun qo'shimcha qilasiz. Shunday yozilgan kod soddaroq chiqadi.

Rasm va matnni moslashtirish

Soya, gradient, shaffoflik

Soyla kodida shu narsalar ishlatilgan app/webapp/index.html boshidagi body qoidasida uchta radial-gradient va bitta linear-gradient ustma-ust qo'yilgan — shuning uchun fon "chuqur" ko'rinadi. Endi u kodni o'qiy olasiz.

transition — yumshoq o'zgarish

transform — siljitish, aylantirish, kattalashtirish

@keyframes — o'zi ishlaydigan animatsiya

Animatsiyani nimaga qo'llash kerak transform va opacity — brauzer uchun "arzon", silliq ishlaydi. width, height, top kabi xossalarni animatsiya qilish telefonda sekinlashishga olib keladi.
Mashq — moslashuvchan tugma va karta.
  • Kartaga transition qo'shib, :hover da yuqoriga 4px siljishini va soyasi kuchayishini qiling.
  • Ekran 500px dan tor bo'lsa, karta ichidagi rasm va matn ustun bo'lib joylashsin (flex-direction: column).
  • Karta paydo bo'lganda @keyframes bilan pastdan ko'tarilsin.
Namuna yechim 
.karta {
  transition: transform .25s ease, box-shadow .25s ease;
  animation: kotaril .45s ease both;
}
.karta:hover {
  transform: translateY(-4px);
  box-shadow: 0 14px 30px rgba(0, 0, 0, 0.16);
}

@media (max-width: 500px) {
  .karta { flex-direction: column; text-align: center; }
}

@keyframes kotaril {
  from { opacity: 0; transform: translateY(16px); }
  to   { opacity: 1; transform: translateY(0); }
}

Xulosa

  • viewport meta tegi — mobil moslashuvning sharti.
  • @media (max-width: ...) — tor ekranga, min-width — keng ekranga qoida.
  • img { max-width: 100% } — rasm chegaradan chiqmasligi uchun.
  • transition — holat o'zgarishini yumshatadi, @keyframes — o'zi ishlovchi animatsiya.
  • Animatsiyada transform va opacity dan foydalaning.
Tekshiruv savollari

1. Telefonda matn juda mayda ko'rinsa, nimani tekshirasiz?
viewport meta tegi borligini.

2. transition ni qaysi qoidaga yozamiz — asosiysiga yoki :hover ga?
Asosiy qoidaga. Aks holda faqat "kirish" silliq bo'lib, "chiqish" keskin bo'ladi.

3. Cheksiz aylanuvchi spinner uchun nima kerak?
@keyframes + animation: ... infinite linear.
