02. Formalar va jadvallar

Forma — foydalanuvchidan ma'lumot olish usuli. Soyla'dagi "Sozlamalar" oynasi ham forma: yosh, til, shahar, suhbatdosh jinsi. Shu darsda barcha kerakli maydon turlarini ko'ramiz.

Eng oddiy forma

Uchta muhim narsa:

  • label — maydon nomi. for va input'ning id si bir xil bo'lishi kerak — shunda yozuvni bosganda kursor maydonga tushadi.
  • name — ma'lumot serverga shu nom bilan boradi.
  • placeholder — bo'sh maydondagi kulrang namuna matn (label o'rnini bosmaydi!).

Input turlari

Telefonda farqi katta type="number" va type="tel" mobil klaviaturani raqamli qilib ochadi, type="email" esa @ ni chiqaradi. Bu foydalanuvchi uchun katta qulaylik.

Tanlash: checkbox, radio, select

Radio ishlamasa Demak name lari boshqa-boshqa. Bir guruh radio tugmalar bir xil name ga ega bo'lishi kerak — shundagina ular bir-birini o'chiradi.

Tekshiruv (validatsiya) — JavaScript'siz

Brauzer o'zi tekshirib, xato haqida ogohlantiradi:

AtributVazifasi
requiredMajburiy maydon
minlength / maxlengthMatn uzunligi chegarasi
min / maxSon yoki sana chegarasi
patternShablon (regular expression)
disabledMaydon o'chirilgan, o'zgartirilmaydi
readonlyO'qish uchun, lekin serverga yuboriladi
autocomplete="off"Brauzer eslab qolmasin
Muhim Brauzer tekshiruvi — faqat qulaylik uchun. Haqiqiy tekshiruv serverda bo'lishi kerak, chunki foydalanuvchi HTML'ni DevTools bilan o'zgartirib yuborishi mumkin. Soyla'da bu app/api/webapp.py va Pydantic modellarida qilingan.

Jadvallar

  • tr — qator, th — sarlavha yacheykasi, td — oddiy yacheyka.
  • Jadval faqat haqiqiy jadval ma'lumot uchun. Sahifa joylashuvi uchun emas — u ish Grid/Flexbox'ning (04-dars).
Mashq — "Sozlamalar" formasi. Soyla sozlamalariga o'xshash forma yozing:
  • Ism (matn, majburiy);
  • Yosh (son, 12–99);
  • Jins — radio: erkak / ayol;
  • Suhbatdosh tili — select: uz / ru / en;
  • Mavzu — checkbox: do'st / juft / o'qish;
  • "Saqlash" tugmasi.
Namuna yechim 
<form>
  <h3>Sozlamalar</h3>

  <p><label for="ism">Ism</label><br>
  <input type="text" id="ism" name="ism" required></p>

  <p><label for="yosh">Yosh</label><br>
  <input type="number" id="yosh" name="yosh" min="12" max="99" required></p>

  <fieldset>
    <legend>Jins</legend>
    <label><input type="radio" name="jins" value="m" checked> Erkak</label>
    <label><input type="radio" name="jins" value="f"> Ayol</label>
  </fieldset>

  <p><label for="til">Til</label><br>
  <select id="til" name="til">
    <option value="uz">O'zbek</option>
    <option value="ru">Rus</option>
    <option value="en">Ingliz</option>
  </select></p>

  <fieldset>
    <legend>Mavzu</legend>
    <label><input type="checkbox" name="mavzu" value="dost"> Do'st</label>
    <label><input type="checkbox" name="mavzu" value="juft"> Juft</label>
    <label><input type="checkbox" name="mavzu" value="oqish"> O'qish</label>
  </fieldset>

  <button type="submit">Saqlash</button>
</form>

fieldset va legend — bir guruh maydonlarni nomi bilan o'rash uchun qulay teglar.

Xulosa

  • Har bir maydonga label bering — for = id.
  • To'g'ri type tanlash mobil foydalanuvchi uchun juda muhim.
  • Radio guruhida name bir xil bo'ladi.
  • required, min, pattern — bepul tekshiruv, lekin serverni almashtirmaydi.
